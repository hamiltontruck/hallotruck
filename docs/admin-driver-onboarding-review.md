# Admin driver onboarding review

The Admin Driver Compliance queue now includes every driver who is not yet approved or suspended, including brand-new registrations with zero uploaded identity documents.

Onboarding stages shown in the existing driver card:

- Waiting for driver documents — 0/5 required identity documents submitted.
- Documents under review — one or more required documents are pending Admin review.
- Corrections required — one or more required documents were rejected and need replacement.
- Onboarding incomplete — documents exist but the required five are not all ready for approval.
- Ready for approval — all five required identity documents are verified; only then is Approve driver enabled.

This does not create a duplicate Admin page and does not weaken the existing 5/5 approval rule.
