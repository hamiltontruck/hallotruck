- Cargo capacity remains owned by the selected truck. Switching units changes the quantity representation: 5 tons = 50 quintals. Display, quote tons and booking quantity/unit now refer to the same load. The server-side quote recheck remains unchanged.
- Oromo/Amharic geocoder responses translate city names, so filtering their labels against a Latin query discarded the correct city. Non-English searches now join localized and English provider results by ID. Verified MapTiler Addis city identity `region.606` is preferred for a matching city-name query; district/POI coordinates are not substituted. Localized labels and provider coordinates are preserved. English search follows its existing path unchanged.
- Driver Vite uses relative base `./` for Capacitor. Resolving it against location.origin lost the deployed `/hallotruck/driver-mobile/` path. Google sign-in now resolves against location.href; URL resolution strips query/fragment. Supabase flow-state referrer inspection confirmed the correct Driver URL is allowed, while the root URL fell back to a stale private-LAN site URL. No auth configuration or users were modified. A full personal Google consent/sign-in still needs a real user.

Validation: Customer suite plus six localized-search service tests; Driver 162/162 tests; strict types and both application builds.
