# V2 mobile visual parity checklist

Source of truth: MagicPath HALLO Web V2 Premium Logistics Landing and Admin/CEO Executive Control Center V2.

Test **both** `/` and `/admin-design` at 320, 360, 390, and 412 CSS pixels.

- [ ] No horizontal overflow or clipped controls
- [ ] Logo, EN/OR/AM selector, navigation and mobile menu accessible
- [ ] Landing hero typography, map illustration and role tabs match MagicPath
- [ ] Admin sidebar opens and closes without covering critical actions
- [ ] Dashboard tables and charts are readable or intentionally horizontally scrollable
- [ ] Keyboard navigation, focus states and minimum touch targets
- [ ] Clearly visible design-only / illustrative-data notice
- [ ] No live-data, revenue, GPS or booking claims without backend verification

Capture screenshots and attach evidence before marking parity PASS.
Netlify V2 preview is independent; do not point the V1 Netlify site at this folder.
