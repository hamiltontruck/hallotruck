# HALLO Driver Mobile App V4

Standalone Driver mobile surface. This app is intentionally separate from the legacy `apps/mobile-app` and from `apps/customer-mobile-app`.

Target GitHub Pages route: `/hallotruck/driver-mobile/`.

Scope: Driver Home, Jobs, Active Trip, Delivery Proof, Wallet/Earnings and Profile. It must reuse the existing HALLO Driver Portal backend/Supabase authorization and business workflows; it must not introduce a second database or weaken RLS/role boundaries.
